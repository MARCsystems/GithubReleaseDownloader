# MARCsystems_GuiElements

A simple release asset downloader that can be used to fetch and download Stable/Pre-Release assets from your repository. Works with Public and Private Repositories.

---

## 📦 Installation

You can install the package from NuGet:

```bash
dotnet add package GithubReleaseDownloader --version 1.0.1
```

Or via Visual Studio Package Manager:

```bash
Install-Package GithubReleaseDownloader -Version 1.0.1
```
